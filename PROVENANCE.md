# Provenance note

The CSV files under `data/manuscript_consistent/` preserve aggregate values transcribed from the accepted manuscript and the manuscript-linked seed-level appendix tables. They are provided to make the released values findable and machine-readable; they should not be mistaken for a complete raw-data deposit.

The original attempt-level ASR log corresponding to the manuscript’s 2,000-attempt denominator was not recovered in the retained project files. A directly observed set of 10,000-attempt materials and a normalized-TTFF reconstruction exist outside this limited manuscript-consistent release and are not substituted here. No missing raw record is synthesized or relabeled.

The release therefore supports inspection of the manuscript-consistent aggregate values and protocol configuration, but does not claim independent regeneration of every historical run or raw attempt-level record.
