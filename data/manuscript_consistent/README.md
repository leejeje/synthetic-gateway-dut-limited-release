# Manuscript-consistent data summaries

These CSV files are transcriptions of values printed in the accepted manuscript and are included for transparent reference. They are not a substitute for the original experimental archive.

## Files
- `table_vii_primary_results.csv`: primary N = 20 policy summary as printed in Table VII.
- `supplementary_s1_manuscript.csv`: Supplementary Table S1 values as printed; TTFF is reported in action steps.
- `supplementary_s2_manuscript.csv`: Supplementary Table S2 values as printed; total denominator is 2,000 per policy.
- `appendix_seed_metrics_transcribed.csv`: per-seed reward/TTFF/NST/RR values transcribed from Appendix Tables A-I–A-VII.

## Provenance limitation
The current workspace did not contain the original attempt-level ASR log for the manuscript's 2,000-attempt denominators. Accordingly, `supplementary_s2_manuscript.csv` is a faithful aggregate transcription, not a regenerated raw attempt log. Do not claim that it independently reproduces the 2,000-attempt ASR procedure. The current workspace also contains a different 10,000-attempt ASR reconstruction and a normalized-TTFF reconstruction; neither is included here as manuscript source data.

The appendix CSV is also a manuscript transcription. It should not be described as raw database output unless the corresponding original database/log provenance is established.
